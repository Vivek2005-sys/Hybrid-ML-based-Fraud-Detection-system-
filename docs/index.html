System Architecture

  • ✓ Dual-Engine Core: Parallel evaluation using a hard-coded JSON Rule Engine and a behavioral XGBoost model.
  • ✓ Real-time Feature Engineering: Live SQL window functions computing velocity and Z-Scores on the fly.
  • ✓ Containerized: PostgreSQL, FastAPI Backend, and Streamlit UI orchestrated seamlessly via Docker Compose.
